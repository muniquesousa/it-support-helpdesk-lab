# IT Support Lab Environment

## Purpose

This lab simulates a small-business IT environment where I perform Level 1 IT support tasks and troubleshoot common end-user issues.

## Role

Junior IT Support Technician

## Organisation

NorthStar Solutions Ltd — fictional professional-services company with approximately 20 employees.

## Environment

The lab uses virtual machines to reproduce common Windows support incidents in a controlled environment.

## Skills Developed

- Windows 11 administration
- Hardware and software troubleshooting
- TCP/IP and network troubleshooting
- User account support
- File and folder permissions
- Command-line diagnostics
- PowerShell
- Incident management
- Technical documentation
- End-user communication
